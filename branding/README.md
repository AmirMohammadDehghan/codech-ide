# Codech IDE identity

The geometric, interlocking mark follows the existing Codech identity found in the user's previous Codech design work. This version is a newly drawn vector adaptation for small software icons; it does not embed an extracted raster image.

- Forest background: `#122019`
- Muted green: `#69B89B`
- Warm gold: `#D4B65E`
- Text: `#D9E2DC`

`codech-ide-app.svg` is the rounded application tile. The transparent small mark is `apps/workbench/media/logo.svg`; `media/icon.png` is its raster export for the VSIX manifest. Avoid metallic gradients and shadows at small sizes. The geometry and gap are intentionally simple enough to read at activity-bar scale.
