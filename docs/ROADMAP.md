# Development roadmap

## Delivered in 0.1–0.2

Central chat, native editors and diffs; Markdown notes and local graphs; Codex and Responses API providers; worktrees and reviewed commits; Graphiti search adapter; independent Windows x64 binary distribution and installer; Open VSX/VSIX installation; native themes; context deltas and configurable API usage/history guards.

## Next: reliable daily workflow

- Durable task event log, restart recovery, session branching and explicit context-checkpoint editor.
- Ignore-file-aware symbol indexing, incremental invalidation and retrieval-quality evaluation.
- File watchers, persistent review records, hunk review and worktree cleanup/snapshots.
- Native skill/MCP/tool management with per-capability permissions and process isolation.
- Versioned Django/React task evaluations on Luna and Terra: success, correction rounds, tokens, latency and total cost.
- Signed installers, update service, macOS/Linux packaging and extension regression suite.

## Knowledge and IDE compatibility

- Full Markdown live preview, frontmatter, embeds, arbitrary vault selection and backlinks panel.
- Reviewed Graphiti ingestion with attribution, expiry and provider-aware cost controls.
- Versioned Obsidian API compatibility host with tests for named plugins; no blanket compatibility promise.
- JetBrains keymap import, Django run/debug/test profiles, database views and refactoring parity matrix.
- GitHub PR workflow, conflict assistance and integrated review conversations.

Do not label the product stable until crash, wrong-worktree, stale-review, provider timeout, cancellation, merge-conflict, malicious-note, symlink-escape and extension-crash scenarios are evaluated. Publish task quality and total-cost measurements separately from context-character reductions.
