Codech IDE now ships as an independent Windows x64 desktop app with its own installer, application identity, settings and extension directory.

- Official SHA-256-verified VSCodium/Code-OSS runtime and bundled Codex 0.166.0.
- Native Open VSX and VSIX extension installation.
- Neutral Graphite default, Paper light theme, optional Forest and native third-party themes.
- Central conversation, source/diff tabs, Markdown knowledge, local graphs, worktrees and human review.
- Per-session context deltas, configurable API output/step/usage limits and bounded history renewal. Terra and Luna presets.
- MIT source, upstream notices and exact runtime provenance.

**Download CodechIDE-Setup-0.2.0-x64.exe** for the independent app. The VSIX is optional for users who want only the workbench inside an existing editor. SHA256SUMS.txt verifies both files.

This is an **unsigned development alpha**. Windows may show publisher warnings. Updates are manual. Obsidian plugin execution, full PyCharm parity, automatic Graphiti ingestion and signed updates are not included. Real paid inference and model quality/cost benchmarks have not been performed; context-character reduction is not a billing-savings claim.

Local validation: 17 tests, strict TypeScript, native standalone host, real Dracula install from Open VSX, three themes, bundled Codex handshake and Windows installer smoke test.
