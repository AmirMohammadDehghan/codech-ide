Codech IDE 0.3 alpha adds a persistent bottom AI composer with editor/diff context, a unified local code/document graph, reference sources, skill import and MCP controls.

The integrated browser now has in-editor web search, an element picker, DOM/style details, source lookup, DevTools and scroll/reveal controls. Codechi is an optional animated companion. Offline Persian dictation uses a verified, optional Whisper.cpp CPU runtime and model download (~199 MB); transcripts remain editable before sending.

Fixes the Codex approvalPolicy error (unlessTrusted → untrusted), thread sandbox spelling and recovery of unpersisted threads.

Windows x64 per-user installer. Unsigned alpha; manual updates. Full Obsidian plugin execution and PyCharm parity are not implemented. Browser inspection uses a proposal enabled in the bundled runtime. Actual Persian-speaker accuracy and Luna/Terra inference quality are not claimed.
