# کدچ آی‌دی‌ای — نسخهٔ ۰٫۲

Codech اکنون برنامهٔ مستقل ویندوز ۶۴ بیتی با فایل اجرایی، نصب‌کننده و پروفایل جداگانه است. پایهٔ آن نسخهٔ رسمی و متن‌باز VSCodium از Code-OSS است. موتور ادیتور را از سورس دوباره کامپایل نکرده‌ایم؛ بستهٔ رسمی با هش بررسی‌شده، نام و لوگوی Codech، ورک‌بنچ و Codex داخلی ترکیب شده است.

## نصب و ظاهر

نصب‌کنندهٔ **CodechIDE-Setup-0.2.0-x64.exe** را اجرا کن. برنامه در منوی Start ظاهر می‌شود و به VS Code یا Codex جداگانه نیاز ندارد. برای Git و زبان‌هایی مانند Python و Node، ابزار همان زبان باید نصب باشد. این نسخه هنوز امضای دیجیتال ندارد.

تم پیش‌فرض **Codech Graphite** خاکستری خنثی است. از دکمهٔ **Theme** یا **Ctrl+K Ctrl+T**، تم روشن **Codech Paper**، تم سبز **Codech Forest** یا تم افزونه‌ای را انتخاب کن. چت و دانش هم رنگ‌های تم ادیتور را می‌گیرند. نصب از Open VSX و فایل VSIX وجود دارد؛ نصب واقعی Dracula در نسخهٔ مستقل آزموده شده است.

گفت‌وگو در صفحهٔ اصلی باز می‌شود. کد و diff واقعی را می‌توان کنار آن باز کرد. یادداشت‌ها در .codech/knowledge با لینک‌هایی مانند [[Architecture]] ذخیره می‌شوند. Worktree از commit فعلی Git ساخته می‌شود.

## اتصال مدل و مصرف

- **ChatGPT / Codex:** از Codex رسمی داخل برنامه و ورود مستقل Codech استفاده می‌کند. دسترسی و سقف مصرف وابسته به حساب است؛ فایل ورود برنامهٔ دیگری خوانده نمی‌شود.
- **OpenAI API:** کلید در SecretStorage نگه‌داری می‌شود و مصرف API جداگانه است. برای آزمایش این نسخه هیچ درخواست پولی مدل ارسال نشده است.
- Terra و Luna در پیشنهادهای مدل هستند؛ فهرست حساب را با **Load model catalog** بگیر. کیفیت هر مدل باید روی پروژهٔ واقعی سنجیده شود.
- بودجهٔ کانتکست پیش‌فرض ۱۲هزار کاراکتر است. ادامهٔ گفت‌وگو فقط بخش‌های تغییرکرده را دوباره ضمیمه می‌کند.
- پیش‌فرض API: حداکثر ۶ پاسخ در هر نوبت، ۳هزار توکن خروجی در هر پاسخ، خروجی ابزار محدود و محافظ نرم مصرف ۱۶هزار توکن. این محافظ بعد از پاسخ بررسی می‌شود و سقف قطعی هزینه نیست.
- هر ۴ نوبت API، زنجیرهٔ تاریخچه با درخواست اصلی، حداکثر چهار پیام اخیر و کانتکست تازه جایگزین می‌شود. تاریخچهٔ میانی به مدل بعدی فرستاده نمی‌شود؛ تعداد نوبت‌ها از **Agent budgets & settings** قابل افزایش است. تصمیم‌های مهم پروژه‌های طولانی را در دانش پروژه ثبت کن.

آزمون نمونه، کانتکست تکراری را از ۶۹۴۴ به ۸۵ کاراکتر کاهش داد. این عدد مربوط به متن تازهٔ ضمیمه‌شده است، نه هزینه، توکن صورتحساب یا کیفیت مدل. سابقهٔ Responses حتی با previous_response_id در مصرف ورودی محاسبه می‌شود. [مستند رسمی OpenAI](https://developers.openai.com/api/docs/guides/migrate-to-responses)

## محدودهٔ فعلی

بازبینی فایل، diff، تأیید وابسته به محتوای دقیق، commit مسیرهای تأییدشده و worktree وجود دارند. گراف import کد و گراف لینک دانش محلی‌اند و مدل لازم ندارند. Graphiti فعلاً اتصال MCP و جست‌وجوی حافظه دارد؛ راه‌اندازی سرویس و ورود خودکار دانش انجام نشده است.

اجرای پلاگین‌های Obsidian هنوز پیاده‌سازی نشده؛ فقط بررسی manifest و امکانات Markdown وجود دارد. جست‌وجوی افزونهٔ میانبر IntelliJ/PyCharm در دسترس است، اما برابری کامل ابزارهای Django، دیتابیس، دیباگ و refactoring ادعا نمی‌شود. نسخهٔ ۰٫۲ آلفاست؛ آزمون هزینه و کیفیت واقعی مدل، امضای نصب‌کننده و به‌روزرسانی خودکار هنوز باقی مانده‌اند.
